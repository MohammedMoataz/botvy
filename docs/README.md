Two of these folders are **temporary** and exist to be emptied. The rest is the
permanent record of what was built and why.

## Waiting on you

| Folder | What is in it |
|---|---|
| 🔨🤔 [**for-you/**](for-you/) | Everything I need from you, both phases: six things to do and six calls to make. One file each, with a box to answer in. **Delete each file as you answer it.** |
| 📖 [**to-review/**](to-review/) | Five things to read and disagree with if you do — including the pre-016 review. **Delete each file as you read it.** |

Start with [`for-you/README.md`](for-you/README.md). If you only do one thing,
do [`for-you/do-1-free-disk-space.md`](for-you/do-1-free-disk-space.md): it is
the only thing blocking both phases.
