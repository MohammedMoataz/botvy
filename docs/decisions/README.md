# decisions/

What was decided while you were away, and what could not be.

You asked for every enhancement to be implemented with the recommended
solution, for P11 to be finished without waiting on you, and for anything that
needed your answer to be written down here with my own default already applied
rather than left as a question blocking the work. That is what these files are.

| File | What it holds |
|---|---|
| [001](001-the-options-i-chose-on-the-enhancements.md) | Every enhancement that offered more than one route, the route taken, and what to say if you want the other one |
| [002](002-what-p11-still-needs-a-machine-or-you-for.md) | The P11 tasks that are not done, what each is waiting for, and the exact command that finishes it |

Nothing here is a question you have to answer for the work to proceed. Each one
already has an answer in the tree. They are written down because a default
taken silently is indistinguishable from a decision nobody made — which is the
failure this repository's own notes keep recording.
